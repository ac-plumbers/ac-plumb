# AC Plumbers Project Deep Scan

Date: January 28, 2026

## Project purpose (high level)
This repo is a static marketing website for **AC Plumbers Ltd.** built with **Astro** + **Tailwind CSS v4** + **Vue** components. It ships to Netlify as a static site (`dist/`). Content for services, areas, and legal pages is stored in `src/content` and rendered via Astro content collections.

## Build & tooling summary
- Framework: Astro (`astro.config.mjs`) with Vue integration.
- Styling: Tailwind via `@tailwindcss/vite` and CSS config in `src/styles/global.css`.
- Deploy: Netlify (`netlify.toml`), static output.
- Scripts: `npm run dev`, `npm run build`, `npm run preview`, `npm run deploy:*`.
- Pre-build: `scripts/copy-images.js` copies service images into `public/images/services`.
